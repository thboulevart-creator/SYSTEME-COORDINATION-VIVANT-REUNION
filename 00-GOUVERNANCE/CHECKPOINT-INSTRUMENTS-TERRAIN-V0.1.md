## Contrôles effectués

- cohérence avec `PROTOCOLE-CARTOGRAPHIE-TERRAIN-V0.1-CANDIDAT` ;
- séparation faits / déclarations / inférences / hypothèses ;
- présence d'une hypothèse nulle ;
- absence de question de vente de solution ;
- collecte fondée sur cas réels avant opinions générales ;
- registre obligatoire des non-problèmes ;
- priorité aux solutions simples avant développement ;
- exclusion des données personnelles non nécessaires ;
- absence d'autorisation implicite de contact ou de développement.

## Décision

Les instruments sont **matérialisés et prêts pour revue**, mais ne sont pas encore qualifiés pour usage terrain.

Aucun contact avec un EPCI, une fourrière, un refuge, une association, une famille d'accueil ou un particulier n'est autorisé par ce checkpoint.

## Prochaine action gouvernée unique

Effectuer une **revue adversariale des instruments terrain V0.1**, avant tout contact.

Cette revue doit tenter de casser le protocole sur au moins les dimensions suivantes :

1. questions orientées ou inductrices ;
2. métriques ambiguës ou impossibles à reproduire ;
3. contamination entre axes A, B et C ;
4. sélection des participants susceptible de fabriquer artificiellement une friction ;
5. confusion entre absence de preuve et preuve d'absence ;
6. critères de qualification trop faciles à satisfaire ;
7. artefacts ou données personnelles collectés sans nécessité ;
8. demande de consentement insuffisamment claire ;
9. conclusions générales tirées d'un petit lot T0 ;
10. architecture future introduite trop tôt ;
11. incapacité à enregistrer les non-problèmes ;
12. incompatibilité entre les instruments et les gates du protocole.
