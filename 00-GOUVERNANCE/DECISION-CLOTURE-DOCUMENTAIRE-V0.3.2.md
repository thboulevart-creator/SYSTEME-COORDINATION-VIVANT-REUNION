# PROGRAM DECISION RECORD — Clôture documentaire V0.3.2

**Date :** 24 septembre 2026

## 1. Décision

La phase de recherche documentaire générale est **close**.

Aucune nouvelle campagne documentaire large n'est autorisée sans apparition d'un besoin précis issu du terrain.

Le retour Claude Research V0.3.2 n'est pas adopté tel quel. Il est remplacé, pour la source de vérité du dépôt, par :

- `02-CARTOGRAPHIE-ECOSYSTEME/CARTOGRAPHIE-V0.3.1.md`
- `02-CARTOGRAPHIE-ECOSYSTEME/CLOTURE-DOCUMENTAIRE-V0.3.2-AUDITEE.md`

## 2. Motif

La documentation publique permet désormais de connaître avec suffisamment de précision :

- les principales catégories d'acteurs ;
- leurs responsabilités générales ;
- les systèmes et registres majeurs ;
- les parcours réglementaires principaux ;
- plusieurs doublons et ruptures candidates ;
- les sources de vérité principales ;
- les limites de l'information publique.

Elle ne permet pas de reconstruire avec assez de précision les opérations réelles aux frontières inter-structures.

L'information marginale la plus utile doit désormais être obtenue par observation ou échanges terrain ciblés.

## 3. Correction déterminante

Un règlement public CASUD de 2025, non intégré par Claude Research, formalise une partie du transfert fourrière → association :

- délai de 8 jours dans le règlement ;
- associations habilitées et déclarées ;
- convention de partenariat ;
- attestation de prise en charge ;
- critères de refus ;
- transfert de responsabilité à la signature.

Cela invalide l'affirmation selon laquelle aucun document public ne formalise F6/F7.

Cependant, les mécanismes qui intéressent directement la coordination restent inconnus :

- proposition ;
- canal ;
- destinataires ;
- délai de réponse ;
- acceptation avant transfert ;
- refus ;
- réservation ;
- départage ;
- outil opérationnel.

Le besoin de terrain reste donc intact.

## 4. Référence réglementaire courante

Pour les règles sanitaires et de protection animale des fourrières, la référence actuelle à utiliser est l'**arrêté du 19 juin 2025**.

L'arrêté du 3 avril 2014 a été abrogé par l'article 35 du texte de 2025.

Tout travail futur doit vérifier la version en vigueur à la date de l'analyse.

## 5. Portée autorisée suivante

La prochaine phase est limitée à la **cartographie terrain**, selon trois axes.

### AXE A — ACCESSIBILITÉ UNIVERSELLE À L'ACTION

Tester la capacité d'une personne, indépendamment de sa langue, nationalité ou connaissance locale, à partir de ce qu'elle observe et à atteindre rapidement l'action correcte.

Mesures candidates :

- temps ;
- sites consultés ;
- appels ;
- ressaisies ;
- erreurs ;
- incompréhensions ;
- actions abandonnées ;
- besoin d'expertise préalable.

### AXE B — PARCOURS INTER-STRUCTURES

Reconstituer les workflows réellement utilisés.

Priorités :

- F6/F7 fourrière ↔ association/refuge ;
- association ↔ famille d'accueil ;
- canaux ;
- outils ;
- délais ;
- accusés de réception ;
- critères de décision ;
- transferts de responsabilité ;
- clôture.

### AXE C — PARCOURS DE L'ANIMAL

Reconstituer, pour un cas réel ou historique suffisamment documenté :

- état administratif ;
- présence physique ;
- détenteur enregistré ;
- responsable opérationnel ;
- demande en cours ;
- acceptation ;
- transfert ;
- issue ;
- prochaine action attendue.

## 6. Scénario de référence

Le scénario suivant est conservé exclusivement comme hypothèse de test :

`CHIEN TROUVÉ`
→ interface unique  
→ commune associée au bon EPCI  
→ procédure correcte  
→ orientation vers le système compétent  
→ suivi  
→ si admissible : demande de prise en charge  
→ réponse association  
→ proposition famille d'accueil  
→ acceptation  
→ transfert confirmé.

Ce scénario ne constitue ni une architecture adoptée ni une spécification de produit.

## 7. Questions centrales terrain

### A

> Peut-on rendre l'action correcte rapide et accessible sans exiger que l'utilisateur connaisse l'écosystème institutionnel ?

### B

> Où l'information ou la responsabilité ralentit-elle, se duplique-t-elle ou se perd-elle entre structures ?

### C

> Peut-on reconstituer sans ambiguïté qui doit agir maintenant et ce qui doit se passer ensuite pour l'animal ?

## 8. Interdictions à ce stade

Aucune :

- plateforme V1 ;
- architecture technique figée ;
- développement ;
- interconnexion présumée ;
- API présumée ;
- automatisation de décisions juridiques ou vétérinaires ;
- affirmation de besoin commercial ;
- classement de solutions avant observation.

## 9. Prochain gate

La prochaine décision structurante doit intervenir **après un protocole terrain préenregistré et une première observation/pilotage borné**.

Le terrain doit permettre de distinguer :

- problème d'information ;
- problème d'orientation ;
- problème de coordination ;
- problème de traçabilité ;
- problème de capacité ;
- problème juridique ;
- problème d'incitation ;
- absence de problème significatif.

Seulement ensuite, les architectures candidates pourront être comparées à des solutions plus simples.
