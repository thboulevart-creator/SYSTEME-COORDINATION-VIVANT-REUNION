# NOTICE-INFORMATION-CONSENTEMENT-V0.1-CANDIDAT

**Statut :** CANDIDAT — à relire avant toute prise de contact  
**Objet :** information des participants aux observations et entretiens du lot terrain T0

---

# 1. Présentation courte

Cette étude cherche à comprendre comment fonctionnent actuellement les parcours liés à la protection animale à La Réunion :

- comment une personne trouve la bonne procédure ;
- comment les structures se transmettent les demandes et responsabilités ;
- comment le parcours d'un animal peut être reconstitué.

L'étude ne part pas du principe qu'un nouveau logiciel est nécessaire.

Elle cherche aussi à identifier les éléments qui fonctionnent déjà correctement.

---

# 2. Ce qui peut être demandé

Selon le type de participation :

- résoudre un scénario fictif de recherche d'information ;
- raconter un cas professionnel réel récent ;
- expliquer un workflow ;
- décrire les outils ou canaux utilisés ;
- montrer, si vous l'acceptez, un document ou écran ne contenant pas de données personnelles non nécessaires ;
- aider à reconstruire un parcours animal de manière anonymisée.

Aucune action réelle concernant un animal n'est requise pour les besoins de l'étude.

---

# 3. Participation volontaire

La participation est volontaire.

Le participant peut :

- refuser une question ;
- interrompre l'entretien ;
- refuser l'enregistrement audio ou vidéo ;
- refuser le partage d'un document ;
- demander qu'une information manifestement personnelle ne soit pas conservée.

Aucun engagement commercial n'est demandé.

---

# 4. Données à ne pas collecter

Le projet ne cherche pas à collecter :

- mot de passe ;
- secret ou clé d'accès ;
- identifiant administrateur ;
- adresse précise d'une famille d'accueil ;
- coordonnées privées d'un propriétaire ou adoptant ;
- dossier vétérinaire nominatif ;
- information personnelle sans utilité pour la recherche.

Si un document contient ces informations, il doit être anonymisé ou seulement observé sans copie.

---

# 5. Conservation

Les résultats destinés au dépôt de recherche doivent privilégier :

- rôles plutôt que noms de personnes ;
- cas anonymisés ;
- données agrégées ;
- traces expurgées ;
- description des workflows plutôt que données individuelles.

Les organisations peuvent être nommées lorsque leur identité est nécessaire à la compréhension du système.

---

Par défaut, les propos sont reformulés et attribués à un rôle générique.

Exemple :

> responsable associatif, entretien T0

Toute citation nominative ou attribution personnelle doit faire l'objet d'un accord spécifique.

---

# 8. Limites

Cette étude :

- n'est pas un service officiel de secours ;
- ne remplace pas une fourrière, un vétérinaire, une association ou une autorité publique ;
- ne constitue pas un audit réglementaire d'une organisation ;
- ne promet pas la création d'un produit ;
- ne cherche pas à évaluer individuellement les salariés ou bénévoles.
