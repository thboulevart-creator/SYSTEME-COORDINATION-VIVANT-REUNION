## 2. Objectif

Reconstituer ce qui est démontrable concernant :

1. où se trouve physiquement l'animal ;
2. quel est son statut administratif ;
3. qui détient l'autorité juridique pertinente ;
4. qui agit opérationnellement ;
5. quelle demande est en cours ;
6. quelle décision a été prise ;
7. quelle action doit venir ensuite.

Ne pas fusionner ces dimensions.
