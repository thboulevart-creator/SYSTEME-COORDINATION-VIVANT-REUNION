# SYSTEME-COORDINATION-VIVANT-REUNION
Recherche et ingénierie d’un système territorial de compréhension, d’orientation et de coordination du vivant à La Réunion : cartographier acteurs, procédures, logiciels et ruptures afin de simplifier les parcours citoyens, fluidifier les échanges inter-structures et orienter chaque situation vers le bon acteur sans remplacer les systèmes existants
